# Материалы для защиты

Готовы SQL-модель с историей товара, Q1–Q10 из core, 11 CSV результатов, DQ и независимые проверки ответов. Текущие цифры: model/reports/core_results.md, архитектура: model/docs/data_model.md, решения: model/docs/decisions.md.

Порядок: проблема и детализация; модель; ответы; доказательства проверок; вброс и история; концепция дашборда; развитие.

На исходном снимке65 DQ:56 PASS,9 SOURCE WARN. Предупреждение о статусе с датой вручения добавлено при согласовании Q7/Q10. Контроль ответов56 PASS. Итоги специальных сценариев показывать по фактическим *_verification.json.

EDA остаётся независимым исследованием исходных CSV. Его старые подписи «SQL следующий этап» относятся к моменту исследования. Современные финальные ответы находятся в model/answers/results/. Корреляция оценки и доставки не доказывает причинность.
