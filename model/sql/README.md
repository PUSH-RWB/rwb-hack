# Сборка core

bash model/build.sh выполняет нумерованные SQL в одной транзакции REPEATABLE READ. 00 пересоздаёт core/mart; история остаётся. 10 строит календарь из данных; 11 задаёт известные статусы и добавляет неизвестные без признания выручки;15 синхронизирует постоянные версии товара. 20 создаёт заказы;21–23 загружают детали;24 независимо агрегирует три дочерние ветки. 30 создаёт витрину заказов,40 — индексы и статистику. Raw только читается.

Версии history.product_versions и watermark history.product_publication обновляются в той же транзакции: ошибка откатывает и их. MODEL_PRODUCT_CHANGE_AT задаёт известное время изменения; иначе используется время наблюдения. Первая версия — явное допущение начального снимка с -infinity. Задним числом переотносить опубликованные продажи обычная сборка не разрешает.
