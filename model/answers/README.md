# Проверенные ответы из core

q01..q05.sql читают только core. Запускаются и экспортируются model/build.sh; results/ содержит полный реальный вывод CSV. Проверки контрольных значений — model/checks/verify_answers.py. Отдельный запрос: bash model/psql.sh --csv -f - < model/answers/q01_monthly_revenue.sql.

Q1 считает все оформленные заказы в месяце, а выручку — только по is_revenue. Q2 считает разные заказы продавца и его единицы товара. Q3 включает доставку. Q4 использует человека и все статусы. Q5 сохраняет неизвестную категорию и категории без перевода. Проценты округлены до двух знаков; сумма округлённых долей может отличаться от 100%.
